# CS340-Client-Server-Development
CS 340 portfolio project featuring a Python and MongoDB rescue animal dashboard with interactive filtering, data tables, and geolocation mapping. 
CS 340 – Client/Server Development

Project Overview

For this course, I developed an interactive rescue animal dashboard for Grazioso Salvare using Python, MongoDB, and the Dash framework. The dashboard allows users to view, filter, and analyze animal shelter data from the Austin Animal Center. It includes an interactive data table, rescue-type filters, and a geolocation map that displays the location of selected animals.

The project demonstrates my ability to integrate a NoSQL database with a Python application and create an interactive interface that supports real-world business needs.

How do you write programs that are maintainable, readable, and adaptable?

I write maintainable and readable programs by organizing my code into reusable components, using descriptive variable names, and including comments that explain important functions. Throughout this course, I learned how separating database operations from the user interface makes an application easier to maintain and update.

For Project One, I developed a Python CRUD module that connects to MongoDB and performs database operations. I reused this module in Project Two to connect the Grazioso Salvare dashboard to the animal shelter database. This approach allowed me to focus on developing the dashboard without rewriting the database connection logic. It also made troubleshooting easier because I could test the database operations separately from the dashboard.

In the future, I could reuse or expand this CRUD module for other applications that require database interactions, such as inventory management systems, customer databases, or reporting dashboards.

How do you approach a problem as a computer scientist?

When approaching a programming problem, I start by reviewing the requirements and breaking the project into smaller, manageable tasks. For the Grazioso Salvare project, I needed to understand how the organization would use animal shelter data to identify potential rescue animals. I then worked on establishing the database connection, retrieving records, creating the interactive table, and implementing filtering and mapping features.

This project differed from previous assignments because it required integrating several technologies into one functional application. Rather than focusing on a single program or feature, I had to consider how MongoDB, Python, and Dash would communicate with one another. I also needed to troubleshoot issues involving callbacks, database authentication, and the interactive map.

For future projects, I would continue using an organized development process that includes analyzing client requirements, planning database structures, testing individual components, and verifying that the completed application meets user needs.

What do computer scientists do, and why does it matter?

Computer scientists design, develop, and improve technology that helps people and organizations solve problems. Their work involves analyzing information, developing software, managing data, and creating systems that improve efficiency and decision-making.

The Grazioso Salvare dashboard demonstrates how software development can support an organization's daily operations. By allowing users to filter animal records based on rescue requirements and view geographic information, the dashboard makes it easier to identify animals that may be suitable for specialized rescue training.

Instead of manually searching through large amounts of shelter data, users can interact with the dashboard to locate relevant information more efficiently. This type of application can save time, reduce manual work, and help organizations make more informed decisions.

Overall, this course strengthened my understanding of client/server development and showed me how databases and interactive applications can work together to solve real-world problems. These are skills I plan to continue developing as I pursue a career in software engineering.
